Verify your download (SHA-256) 

# Download checksums file
wget https://github.com/YOUR_USERNAME/bnl-os/releases/download/v1.0.0/SHA256SUMS

# Verify full image
sha256sum -c SHA256SUMS --ignore-missing

# Expected output
bnl-os-1.0.0-full.wic.gz: OK
SHA-256 Checksums — v1.0.0 a3f8c2d1e5b94760f2c8e3a1d7b5f9e2c4a6d8f0b2e4c6a8d0f2b4e6c8a0d2f4 bnl-os-1.0.0-full.wic.gz
b1d3e5f7a9c2e4f6a8b0d2f4a6c8e0b2d4f6a8c0e2b4d6f8a0c2e4b6d8f0a2c4 bnl-os-1.0.0-minimal.wic.gz

Flash to storage

Use bmaptool (recommended) or dd to write the image.

USING BMAPTOOL (FASTER)

# Install bmaptool
sudo apt install bmap-tools

# Flash (replace /dev/sdX with your device)
sudo bmaptool copy bnl-os-1.0.0-full.wic.gz /dev/sdX

USING DD

gunzip -c bnl-os-1.0.0-full.wic.gz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
⚠️ Double-check your device path with lsblk before running dd. Writing to the wrong device will overwrite data permanently.
