BNL-OS Documentation

BNL-OS is a professional agentic operating system designed for high-performance security and productivity tasks. Unlike traditional Linux distributions, BNL-OS is shipped as a pre-built hardware image optimized for specific target machines.

This documentation provides the steps to install BNL-OS, configure its AI features, and manage system updates.

ℹ️ BNL-OS images are cryptographically signed. Always verify the checksum before flashing.

Installation Guide

To use BNL-OS, you do not need to build it from source. Simply download the official image for your hardware and flash it to a bootable drive.

1. Download the Image

Visit the Downloads page and select the version compatible with your hardware (x86-64 or ARM64).

2. Prepare the Media

You will need a high-speed USB 3.0 drive or SD Card (minimum 16GB). We recommend using one of the following tools:

  • BalenaEtcher (Cross-platform, easy to use)
  • Rufus (Windows only, fast and reliable)
  • dd (Linux/macOS command line)

3. Flash the Image

Select the downloaded .wic.gz or .iso file and your target drive in the flashing tool, then click Flash/Start.

⚠️
Flashing will erase all data on the target drive. Ensure you have backed up any important files.

Sentinel Plane

Sentinel is the security heart of BNL-OS. It monitors every system call and network packet using eBPF hooks, providing real-time threat detection and automated rollback capability.

Chronos Timeline

The Chronos interface replaces the traditional desktop. It visualizes your system state as a timeline, allowing you to instantly revert to previous snapshots or plan future automated tasks.

HackingEdu Introduction

BNL HackingEdu is a security orchestration and education platform designed to provide a safe, AI-assisted environment for learning offensive and defensive cybersecurity.

💡
HackingEdu integrates directly with BNL-OS for advanced lab orchestration, but it can also run as a standalone Electron app on Windows and Linux.

AI Tutor Engine

The AI Tutor is an always-on assistant that helps you navigate complex labs. It uses a "Second Brain" architecture to remember your progress and provide contextual hints.

Lab Orchestration

HackingEdu handles target lifecycle, flag validation, and evidence persistence through its integrated lab runtime.

Privacy Stack

Built-in privacy protection including WireGuard tunnels and Cloudflare WARP rotation.

OTA Updates

BNL-OS uses an A/B partition layout. Updates are downloaded in the background and applied to the inactive slot. On reboot, the system automatically switches to the updated version.

Image targets

BNL-OS provides three image targets:

  • bnl-image-minimal — kernel + init + busybox only
  • bnl-image-full — recommended; includes networking, dropbear SSH, and base utilities
  • bnl-image-dev — full image plus development tools (gcc, gdb, strace)

Flashing

See the Download page for detailed flashing instructions using bmaptool and dd.

OTA updates

BNL-OS uses an A/B (dual-bank) partition layout. At runtime, one bank is active while the other is available for updates. After a successful update, the bootloader flips the active bank. If the new bank fails to boot three times, it automatically reverts to the previous good bank.

Trigger an OTA update manually

# Check current active slot
bnl-update --status

# Apply an update bundle
bnl-update --apply /path/to/bnl-os-1.1.0.swu

# Reboot to activate
reboot
💡 Update bundles (.swu) are generated by the bnl-image-update BitBake target and are signed with a device-specific key.
