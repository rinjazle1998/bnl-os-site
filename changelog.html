Release history

Changelog

Every change, every version. Tags: NEW new feature   FIX bug fix   UPD update   BRK breaking change.

v1.0.0 Latest stable Download 2025-06-01

First stable release of BNL-OS. Built on Yocto Scarthgap (5.0) with Linux 6.6 LTS.

NEW Initial public release of BNL-OS 1.0.0
NEW Yocto Scarthgap (5.0) build system with meta-bnl and meta-bnl-bsp layers
NEW Linux kernel 6.6.21 LTS with BNL-specific configuration
NEW A/B dual-bank OTA update mechanism with automatic rollback
NEW Read-only rootfs with dm-verity integrity verification
NEW Three image targets: minimal, full, dev
NEW BSP support for ARMv7 and AArch64 reference hardware
NEW Kas-based build management for reproducible layer checkout
v0.9.0 Beta 2025-04-10

Beta release. Feature-complete but not yet hardened for production.

NEW A/B partition layout implemented; rollback logic working on test hardware
NEW Dropbear SSH server added to bnl-image-full
UPD Kernel bumped from 6.6.15 to 6.6.21 — includes upstream security patches
FIX Fixed intermittent boot failure on cold start caused by eMMC initialisation timing
FIX Corrected systemd unit dependency ordering causing network to start before interface was ready
v0.8.0 Alpha 2025-02-22

Alpha. Core build system established; not suitable for production use.

NEW Initial meta-bnl layer with distro policy and base image recipe
NEW Linux 6.6 LTS as the default kernel; u-boot as bootloader
NEW Minimal image boots successfully on AArch64 reference board
BRK Partition layout changed from single-rootfs to A/B — existing builds are not compatible
