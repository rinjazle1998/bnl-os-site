Getting Started

Prepare Your Environment.

Both BNL-OS and BNL HackingEdu are currently in active development. Follow these steps to set up the developer environment.

BNL-OS Titan

Hardware Image • Flashable Media
Download Image

Get the official BNL-OS Titan image for your hardware from the downloads portal:

Go to Downloads
Select Flashing Tool

We recommend using BalenaEtcher or Rufus to prepare your bootable media.

Flash & Boot

Connect your USB drive, select the image, and hit start. Once finished, boot your target hardware from the USB.

💡
For industrial deployments, you can use the command-line bmaptool for significantly faster flashing speeds.

HackingEdu App

Desktop Application • Security Suite
Download Installer

Download the latest installer package for your operating system (Windows, Linux, or macOS):

Get Installer
Install Application

Run the installer and follow the on-screen instructions. The application will set up necessary sandboxed environments automatically.

Launch & Verify

Launch BNL HackingEdu from your applications menu. On first run, it will perform a quick system check to ensure all security modules are active.

💡
The app includes a built-in update engine that will notify you when new security modules or lab environments are available.
